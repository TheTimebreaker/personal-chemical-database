Do you want to easily find data for your commonly used molecules?

Do you like having your stuff accessible in one place, with sources so it is easy to reference later?

Does your boss force you to use a shitty ELN (electronic lab journal) that has either no or only disfunctional molecule management, meaning you have to search for this one NMR every single time, driving you a little bit closer to drinking that fuming liquid in your lab that nobody really knows what it is and hoping you never wake up again?

Well, this little project aims to help you.

<h2>Features</h2>

* Fully local database.
* Adding molecules and data is easy!
* Add a source for a piece of data, so you can find the source later (e.g. to cite it).
* Search allows for quickly finding what you're looking for.
* Simple, self-explaining UI.
